05 · Application rules

  • Hierarchy comes from type, alignment and whitespace.
  • Course rows and progress sit directly on white.
  • Use one relevant paper detail, not a panel system.
  • Keep neutral utilities separate from hand-drawn artwork.
  • No gradients, textures, glossy rendering or heavy shadows.
  • Use the authored flame for a continuous-learning streak.

Unspecified stays explicit

Feedback palettes, body/learning type, form controls, pressed/loading states and responsive behavior are extensions awaiting further source/state review. Raw Figma tracking is recorded, not guessed. This is a system update, not a full screen/navigation port or accessibility certification.
