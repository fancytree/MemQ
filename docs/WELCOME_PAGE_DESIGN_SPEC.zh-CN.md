# 欢迎页设计命题（MemQ 新手引导第 1 屏）

这不是施工图。场景怎么编、画什么、怎么动，由设计决定。
这份文档说三件事：**这一屏要让人读到什么**、**动画要替它说什么**、
**哪些东西是 app 的身份不能换**。

参考机型：iPhone 17 Pro，402 × 874 pt。单位是 pt。

---

## 一、这一屏要说的事

一句话：**"这里记的是你自己真正用得上的东西，不是别人整理好的。"**

这是产品的立身之本，也是这一屏唯一的任务。
它是六屏引导的第一屏——产品的理由（为什么读一遍不够）和用法（每天的三步循环）
各自是后面独立的一屏，**这一屏不要碰**。

这句话天生带一个对立面，而且这个对立面是画面最好的素材：

| 不是这个 | 而是这个 |
|---|---|
| 商店里一摞封面精美的现成卡组 | 你自己干活时产生的东西 |
| 别人划的重点 | 你自己卡住过、查过、用过的那部分 |
| 一万词书从 abandon 开始 | 你这趟真的要说的那几百个词 |
| 下载了没打开 | 本来就在手边 |

让人读到的那句潜台词是：

> *这里面的东西都是我自己的。所以我不会想扔掉它。*

不要罗列卖点。不要把"AI""智能""高效""科学记忆法"当形容词用。
（画面里**可以**出现"你和 AI 的那段对话"作为材料来源——那是个具体的东西，
不是形容词。见第二节第 3 条。）

---

## 二、画面要让人读到的东西

按重要性排。第 1、2 条必须传达到，第 3 条看时机，第 4 条是底线。

### 1. 这些材料看得出是"你自己的"

画面里出现的材料，要一眼看出是**从你真实干活的地方来的**，
而不是被谁打包好递过来的：你自己记的笔记、你标注到一半的 PDF、
你刚才问出来的那段话、你随手存下的一个链接。

**可以有的质感**：手写感、划过线、折角、标黄、未读完、不整齐。
**要避开的质感**：封面、商品、整齐划一的套装、"精选""热门"这类货架语言。

真实的东西是有使用痕迹的。这一点比画得漂亮重要。

### 2. 对立面可以直接画出来

第一节那张表就是现成的分镜。如果画面能同时呈现"别人整理好的"和"你自己的"
两种东西，并且让人一眼看出后者才是这里要的——这一屏就成了。

怎么呈现随意：并置、替换、前者褪去后者留下、前者整齐后者有温度……
**但别画成贬低**。现成卡组不是敌人，它只是不是你的。
语气是"这里不一样"，不是"那些都是垃圾"。

### 3. 材料的来源不止一处，而且会越来越近

现在：你的笔记、你的 PDF、你给的一个题目。
接下来：**主流 LLM 的 MCP 接入**——你在 ChatGPT / Claude 里刚问明白的那件事，
可以直接变成卡片。

这件事对理念是正中靶心的：*你问出口的问题，定义了什么对你有用。*
没人比你更清楚你卡在哪。

⚠️ **但是**：MCP 还没上线。如果这屏上线时它还没发布，
画面**不能把它画成已有功能**。两种安全的处理：
给"来源"留出一个开放的、可扩展的视觉位置（不点名具体产品），
或者这一屏完全不碰来源、留给第 3 屏（怎么用）去讲。
千万不要出现任何第三方产品的 logo 或可识别界面。

### 4. 吉祥物在场

小紫怪是这个 app 的角色，六屏它都在。它可以是主角、旁观者，
也可以和材料互动——挑、捡、抱、藏起来都行。
唯一要求：**它别表现得费劲或者苦**。它是来陪着的，不是来替用户发愁的。

### 5. 关于"这类人不止一种"

之前的版本让三种身份（考试 / 语言 / 专业）轮流出现。
这个手法可以留，但**重心要换**：轮换的不再是"你是谁"，而是
**"你手上的东西是什么"**——那份会议纪要、那半篇论文、那个你问过的概念。
身份自己会从材料里透出来，不用点名。

仍然**一次只呈现一个**。三个同时摆出来就变回功能列表了。

## 三、动画要体现的东西

这一屏必须是活的。静止的欢迎页在这个 app 里不成立——
登录页、等待页、首页的背景都在动。但动画要替画面说话，不是炫技。

### 1. "这地方是活的，不是一张图"

画面要有持续的、不求人注意的呼吸感。
**判断标准**：盯着看十秒不觉得吵，瞥一眼能看出它在动。

### 2. "它没有在循环"

多个运动的节奏要彼此错开，让画面不会周期性地回到同一个排列。
一看就在 loop 的背景，会把整个产品显得廉价。
（实现上的做法是让各自的周期互不整除——怎么做随意，但这个效果要有。）

### 3. "轮换是换了一样东西，不是切了一张幻灯片"

如果用了第二节第 5 条的轮换，它是这一屏唯一**有信息的**动画。
它要读起来像"手里换了一样东西"，而不是 PPT 翻页。
淡入淡出、物件替换、局部变形都行——但**别用整体滑动或翻转**，
那会和画面本身的呼吸撞成两重运动。

### 4. 如果画"材料变成卡片"，它必须读起来是"转化"

不是把东西从左边搬到右边。是那份乱的、你自己的材料，
**变**成了可以每天过一遍的小块。
搬运说的是"我们帮你整理"，转化说的才是"它还是你的，只是换了个形状"。

### 5. 不许抢文字

标题和按钮是这一屏要人读的东西。任何运动都不能让眼睛从它们身上被拽走。
**具体就是**：别用快速、尖锐、带弹跳回弹的曲线，别有任何东西从画面外飞进来。
慢、软、小幅度。

### 6. Reduce Motion

系统开"减弱动态效果"时，全部**停在各自的完成态**，不是停在起始的空状态。
一张静帧要是完整的画面，不能是动画还没开始的样子。

## 四、不能换的身份

这几样是整个 app 共用的，换了就不是 MemQ 了。构图随意，但这些要在。

### 4.1 深度只有一种做法：ledge

**没有阴影。** 每一个浮起来的面都是两层：深色外壳 + 浅色面，面向上偏移，
让外壳在**底边**露出一条色带。这条色带是全部的立体感。

```
lead    5pt   一屏上唯一那个实心主按钮
raised  3pt   承载内容的卡片
control 2pt   小控件：chip、开关、小按钮
```

容易画错的地方：外壳 = 面 + 唇。一个 60×60 的方形面要配 60×62 的外壳，
反过来画，面就变成 60×58 了。

### 4.2 不许出现

阴影 / 面上的渐变（渐变只有背景和前景山两处）/ 描边边框当分隔 /
emoji / 全大写加字距的小标签 / 发光 / 毛玻璃 / 小圆角。

圆角一律很大：卡片 22–32，主按钮 42（接近胶囊），小控件 16–20。

### 4.3 色板

| token | 值 | 用途 |
|---|---|---|
| `gradientStart` | `#f3ffa6` | 背景渐变 第 1 停 |
| `gradientBright` | `#f6ff7c` | 背景渐变 第 2 停 |
| `gradientSoft` | `#f5f7c0` | 背景渐变 第 3 停 |
| `canvas` | `#fcfced` | 背景渐变 第 4 停；浅底 |
| `white` | `#ffffff` | 卡片的面 |
| `border` | `#e5dfeb` | 卡片/控件的外壳（那条唇） |
| `primary` | `#6c3cbc` | 主按钮的面、强调、图标线条 |
| `deep` | `#4b2c78` | 主按钮的外壳；最深的墨 |
| `darkest` | `#301a50` | 标题与正文 |
| `muted` | `#795ba3` | 次级说明 |
| `track` | `#f0e4fc` | 极浅紫底 |
| `streakBorder` | `#c59af0` | 中紫，弱线条 |
| `selected` | `#f4fab1` | 选中态的浅黄 |

吉祥物自身（不可改）：`ink #4B2C78`、`body #C59AF0`、`plate #F0E4FC`、
`gold #FFBA00`、`white #FFFFFF`。

主色是黄绿色的天 + 紫色的内容。这个撞色是这个 app 最容易被认出来的东西。

### 4.4 字体

**Geist**，全部。字间距 0。

| 角色 | 字重 | 字号 / 行高 | 颜色 |
|---|---|---|---|
| 大标题 | `Geist_600SemiBold` | 27 / 34 | `darkest` |
| 正文 / 说明 | `Geist_500Medium` | 15 / 22 | `muted` |
| 主按钮 | `Geist_500Medium` | 22 / 30 | `white` |
| 小标签 | `Geist_500Medium` | 12 / 16 | `muted` |

标题不超过两行。

### 4.5 背景的地面

整个 app 站在同一块地上：**自上而下的黄绿渐变 + 两道山形**。

- 渐变：`#f3ffa6 → #f6ff7c → #f5f7c0 → #fcfced`，停点 `0 / 0.21154 / 0.44712 / 1`，竖直，铺满
- 远山：`assets/home-figma/wave-back.svg`，纯色 `#EEFC41`
- 近山：`assets/home-figma/wave-front.svg`，自带一条竖直渐变（顶部 `#FAFE9A` → `#EAFB40` → 底部透明）

两道山在画面上半部，左右都出血。它们也在缓慢移动（见第三节第 1、2 条）。
场景可以和山互动、挡住山、让东西站在山上——但这块地别换掉。

### 4.6 六屏共用的外壳

这三样在六屏里位置完全一致，场景不要占用它们的位置：

- **左右留白 16**
- **顶部进度点**：6 个点居中。当前是 20×6 的胶囊（`primary`），
  已过是 6×6 圆点（`streakBorder`），未到是 6×6 圆点（`border`）。
  左边有返回键（欢迎页隐藏但占位，好让点落在屏幕中线上）
- **底部主按钮**：全宽，高 64（面 59 + 唇 5），圆角 42，
  外壳 `deep` 面 `primary`，文字白色居中。距底部安全区 12

中间剩下的全部空间都是场景的。

## 五、文案

现在代码里的标题是 `For what you still need next month`，
它说的是"什么时候需要"，**没有说出理念里那个对立面**，所以应该换掉。

候选方向（都还没定，可以重写，也可以用中文）：

- 讲归属：*Only the things you actually needed*
- 讲来源：*It starts with your own material*
- 讲对立面：*Not someone else's deck*

按钮现在是 `Why it works`，接第 2 屏（为什么读一遍不够），可以沿用。

轮换的那几条，建议从"身份"改成"手上的东西"，例如
*那半篇你标到一半的论文* / *上周的会议纪要* / *昨天问明白的那个概念*。
措辞你定，守住：具体、有使用痕迹、不吹。
如果画面用图把来源讲清楚了，这几条文字可以完全去掉。

语气：平实。没有感叹号，没有"轻松""秒懂""高效"。

## 六、可访问性

- `muted #795ba3` 在白底上约 5.3:1；比这更浅的灰紫只能用于输入框占位
- 背景、山、插画全部不可交互，不拦触摸
- 最小点击区 40×40
- 装饰性的轮换文字不要打断读屏

---

## 七、交付

1. **402 × 874 的静帧**
2. 场景**分层**，会动的元素各自一层
3. 两道山用原 SVG，别压平成位图
4. 文字层可编辑，Geist
5. 动效给个说明或样片都行——第三节那五条能对上就可以，
   具体用什么曲线、多长周期，你定

## 八、附录：它在一个六屏序列里

欢迎页是第 1 屏。后面五屏共用同一块地、同一个吉祥物、同一行进度点、
同一个底部按钮，区别只在中间那块：

| # | 内容 | 中间那块 | 吉祥物情绪 |
|---|---|---|---|
| 1 | **给谁用** | ← 这一屏，你要画的 | 中性/微笑 |
| 2 | 为什么需要 | 自绘的遗忘曲线，边画边出现 | 闭眼打盹 |
| 3 | 怎么用 | 三个格子轮流点亮（材料 → 变成卡片 → 你复习）<br>MCP 上线后，"材料"那一格会多出 LLM 对话这个来源 | 开心 |
| 4 | 叫什么名字 | 单行输入框 | 中性 |
| 5 | 每天几张 | 一行五个数字 chip | 惊喜 |
| 6 | 什么时候提醒 | 12 个时间 chip | 中性 |

第 2–6 屏的内容都装在一张白卡片里（外壳 `border` + 底唇 3，圆角 32，内边距 20）。
**第 1 屏现在故意没有卡片**——它是欢迎，不是提问。你可以沿用这个判断，
也可以推翻它，只要理由在画面上站得住。
