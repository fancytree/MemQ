# 官网改版计划

目标：让 MemQ 官网在桌面和移动端延续 Today 的明亮、有节奏的学习体验，同时使用可核实的产品内容。

1. 视觉基底：荧光黄绿、深紫、奶油白和白色；Geist 用于正文，Oswald 用于大标题；沿用圆角卡片与紫色底边。
2. 首页结构：品牌导航、主视觉、真实产品展示、学习流程、功能与下载/联系入口；避免未上线功能和无效链接。
3. 动效：主视觉柔和浮动和波浪、交互反馈、内容入场；支持减少动态效果。
4. 真实截图：优先使用运行中版本和不含私人信息的演示数据。未经确认不将个人账户内容放入官网。
5. 验证：桌面及窄屏检查、交互和链接检查；确认官网目标目录后同步改动。
6. MCP：完成用户身份验证、创建/添加工具和官网授权页，验证权限边界与事务行为后再上线。
